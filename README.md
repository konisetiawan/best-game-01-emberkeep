# Emberkeep

Emberkeep - Defend the Last Hearth is an original top-down arena defense game where you hold the last warm refuge against waves of creatures drawn to its flame.

Controls: WASD or arrow keys move, mouse aim, click or Space shoot, Shift dash, P pause, R restart.

Run with `node serve.ts`, then open http://localhost:8080.
